# Kladivo

Neue Website der Bau- & Möbeltischlerei H.-J. Kladivo in Rathenow (bisher `tischlerei-kladivo.de`).

Reines HTML und CSS, kein Build-Schritt. Gestaltet nach den Regeln des Design-Skills [Hallmark](https://github.com/Nutlope/hallmark), eigene helle Farbwelt (warmes Weiß, Logo-Orange, Logo-Grau als Schriftfarbe), aufgebaut auf dem Hallmark-Theme „Formwork“.

## Dateien

- `index.html`: Startseite mit Leistungen, Leitsatz, Anfahrt, Partnern und Kontakt
- `impressum.html`, `datenschutz.html`: Rechtstexte
- `assets/css/`: `tokens.css` (Farben, Schriften, Abstände), `base.css` (Grundregeln), `site.css` (Seitenlayout)
- `assets/fonts/`: Oswald, Archivo und Archivo Narrow als lokale Dateien (SIL Open Font License), damit nichts von Google geladen wird
- `assets/img/`: Logo (freigestellt aus dem bisherigen Logo) und Favicon

## Ansehen

`index.html` im Browser öffnen. Zum Veröffentlichen reicht es, alle Dateien auf den Webspace hochzuladen.

## Datenschutz

Keine Cookies, kein Tracking. Die OpenStreetMap-Karte lädt erst nach Klick.
